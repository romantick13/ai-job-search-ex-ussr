# Contributing

Спасибо, что хотите помочь. Этот проект делает **один человек в свободное
время**, поэтому пара слов о том, как выглядит работа с issue — чтобы у вас
и у меня были реалистичные ожидания.

## Реалистичные ожидания

* Отвечаю на issue не всегда быстро. Реальный ориентир — **дни, а не часы**.
  Иногда дольше: это хобби, а не работа.
* Могу не ответить вообще — не потому что ваш issue плохой, а потому что
  времени не было. Не принимайте это на свой счёт.
* Пул-реквесты принимаю, если они проходят тесты и не ломают то, что работает.
  Крупные переделки — сначала issue, чтобы обсудить подход, а не тратить
  ваше время на PR, который придётся переделывать.
* **Никаких обязательств по срокам.** Если фича не сделана за месяц — это
  нормально, а не пренебрежение.

## Чем помочь реально полезно

По убыванию полезности на единицу потраченного вами времени:

1. **Починить сломанный портал.** Самая частая поломка — портал поменял
   вёрстку или формат фида. Починить — 15 минут, если разобраться.
2. **Прислать баг-репорт** с журналом из `C:\Users\<юзер>\ai-job-search-by\logs\`
   (без ключей: ключи живут в `local.json` и в логи не пишутся).
3. **Перевести интерфейс** (см. «Переводы»).
4. **Добавить портал** (см. ниже).
5. Всё остальное.

## Добавить портал

Портал подключается в четыре шага. Перед стартом прочитайте
[`portals-catalog.md`](portals-catalog.md) — там же чеклист
проверки ToS. Вход в код — только через гейт карточки: новый статус
фиксируется цитатой и датой в `tos_evidence` реестра; код без карточки
не пишется.

### 1. Проверить правила сайта (обязательно, **до** написания кода)

Найдите действующие ToS / пользовательское соглашение / robots.txt.
Зафиксируйте: название документа, номер пункта, дату редакции, точную
цитату — и программный снимок страницы. Снимок хранится локально, в
репозиторий не публикуется: полные копии чужих ToS в публичном репо не
размещаем — в реестре достаточно цитаты, ссылки и даты проверки.

Определите статус:

| Что нашли | `tos_status` | В цепочку по умолчанию |
|---|---|---|
| Явный запрет скриптов/парсинга | `forbidden` | ❌ никогда, запись в graveyard |
| Разрешение или отсутствие запрета — с зафиксированной цитатой | `allowed` | ✅ |
| Есть официальный API | `official_api` | ✅ (через API, не скрапим) |
| Ничего не нашли / непонятно | `unverified` | ❌ выключен, пока не проверите |

**Правило по умолчанию — запрет.** Пока статус не `allowed` или
`official_api`, портал не включается в цепочку. Это медленнее, зато README
не врёт.

### 2. Запись в реестре

Добавьте объект в `config/registry.json`:

```json
{
  "id": "example-com",
  "name": "Example",
  "domain": "example.com",
  "country": "BY",
  "access": "none",
  "tos_status": "allowed",
  "tos_evidence": "ToS example.com/terms, §N: «дословная цитата», редакция 2026-XX-XX; снимок снят программно и хранится локально (в репо не публикуется)",
  "default_enabled": true,
  "adapter_implemented": true,
  "requires_ai": true,
  "notes": "Что это за портал и чем он отличается от остальных."
}
```

`tos_evidence` (цитата/ссылка + дата проверки) **обязателен** при
`allowed` — генератор счётчиков валидирует это и падает без записи.
`requires_ai` означает «нужна ли адаптация текста под вакансию» — поле
влияет на расход квоты.

### 3. Адаптер

Контракт — в исходниках проекта: `IPortalService`
(`src/AiJobSearchBy/Portals/IPortalService.cs`), реализация — наследованием
одного из базовых классов: `ApiPortalBase` (JSON API), `FeedPortalBase`
(RSS/Atom), `ScrapePortalBase` (polite-скрапинг), его наследники
`BrowserEmulationPortalBase` (браузерная эмуляция выдачи — зеркала hh) и
`GovernmentPortalBase` (строгий polite-crawl) — а не HTTP-обвязка с нуля.

Требования:

* **Не бросать исключения наружу.** Ошибка адаптера — это состояние
  адаптера, а не краш всего прогона: возвращайте результат со статусом
  (`PortalResult`), а не исключение.
* **Уважать `CancellationToken`** — иначе отмена прогона не работает.
* **Polite-crawl без сюрпризов:** паузы с рандомизацией, уважение
  robots.txt, `X-RateLimit` / `Retry-After`, честный User-Agent. К одному
  порталу — последовательно, без параллельных запросов.
* **Не хардкодить лимиты.** Кулдауны живут в `rate-limit.json`, лимиты
  API читаются в рантайме из самого портала (hirify) — не из кода.
* **Покрыть тестом на фикстуре.** Фикстура — сохранённый HTML/JSON в
  репозитории; тест не ходит в сеть. Фикстуры — синтетические или
  обезличенные: чужие резюме и персональные данные в репозиторий не
  попадают ([CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)).

### 4. Обновить счётчики

```bash
python tools/gen_readme_counters.py
```

Скрипт пересчитает таблицу порталов в README и **упадёт**, если: в реестре
появился запрещённый портал в цепочке, у `allowed`/`browser_view`-портала нет
`tos_evidence`, или счётчик разошёлся с `expected_counts` (тогда обновите
и `expected_counts.authless_default`). Это намеренно.

## Переводы

Интерфейс использует ресурсы Avalonia (`.resx`): `Strings.ru.resx`,
`Strings.en.resx`. Белорусский — отдельный `Strings.be.resx`.

Правка перевода — это правка `.resx` и pull request: собирать проект у
себя не обязательно, сборку и проверку сделает CI. Белорусский принимается,
если перевод сделан целиком: частичный перевод хуже отсутствующего.

## Ключи при отладке

Свои ключи для локального запуска кладите в
`C:\Users\<юзер>\ai-job-search-by\state\local.json` — он в `.gitignore`. Ключи не
коммитятся никогда: CI-джоб `secrets-guard` блокирует merge. На скриншотах
ключей быть не должно (см. [SECURITY.md](SECURITY.md)).

## Стиль кода

* C#, .NET 10, `Nullable enable`, соблюдаем `.editorconfig`.
* Граф-комментарии `// FLOW`, `// LIFECYCLE`, `// STATE`, `// THREAD` —
  там, где без них не разобраться. Не для каждой строки.
* Экспортёры используют системный шрифт Segoe UI (входит в Windows 10+,
  кириллица из коробки); недоступное семейство — честное исключение,
  а не тихая замена (docs/TROUBLESHOOTING.md). Порчу шрифтов ловит
  golden round-trip тест PDF→PDF.
* Один коммит на одну фазу: `phase-N`, с документацией в том же коммите.
* **Код без обновлённых доков не коммитится**: документация —
  часть системы.
* Никаких новых рантаймов: без EF, без Python в рантайме, без Node.

### Комментарии-графы

```csharp
// FLOW: ServiceA -> ServiceB — направление данных между сервисами
// LIFECYCLE: creates ServiceX — где создаётся инстанс
// STATE: — изменяемое поле/состояние
// THREAD: — на каком потоке живёт код
```


## Тесты

```bash
dotnet test
```

Тесты не ходят в сеть: ИИ-провайдеры — на моках, порталы — на фикстурах.
Golden round-trip PDF→PDF (разбор через PdfPig) ловит порчу шрифтов.
Тест-guard проверяет, что ключи не попадают в журналы.

## Коммит и PR

* Один PR — одна тема.
* В описании PR: **что** изменилось, **почему**, и **как проверить руками**.
* Если изменение видно пользователю — перечислите его в описании PR
  (журнал релизов ведёт мейнтейнер).
* Приложите скриншот, если изменился интерфейс (без ключей и личных данных).
