# Дисклеймер и правовые уведомления

Прочитайте перед использованием. Коротко: **вы сами отвечаете за то, как используете
этот инструмент и за соблюдение правил сайтов, с которых он берёт вакансии.**

---

## 1. Правила сайтов (ToS) — ваша ответственность

Программа обращается к вакансиям на сторонних сайтах. У каждого сайта есть свои
правила использования, и они **различаются**:

| Сайт | Статус проверки ToS | Поведение в программе |
|---|---|---|
| Порталы с официальным API | Разрешено | Работают через API |
| Порталы без запрета на автоматический доступ | Разрешено | Работают |
| Порталы с явным запретом (скрипты/роботы) | **Запрещено** | **Отключены, см. `portals-graveyard.md`** |
| Порталы со статусом «не проверено» | Неизвестно | **По умолчанию выключены** |

Программа не может гарантировать, что условия конкретного сайта не изменятся после
вашей установки. Если сайт изменит правила — сообщите об этом:
[issue «Портал сломался / ToS изменился»](.github/ISSUE_TEMPLATE/portal_broken.yml).

**Что это значит для вас:**

* Автоматический сбор вакансий с сайта, чьи правила это запрещают, может нарушать
  договор, заключённый вами с этим сайтом. Ответственность — на пользователе.
* Сбор персональных данных (ФИО, контакты, зарплатные ожидания) третьих лиц
  (соискателей) регулируется законодательством о персональных данных
  (в Республике Беларусь — Закон № 305-З «О защите персональных данных»).
  Программа отображает вакансии и передаёт выбранные вакансии в AI-провайдер
  только по вашему явному действию — не собирайте и не пересылайте чужие
  персональные данные без основания.
* Автоматическая отправка откликов («подача») в v1 **не реализована** намеренно:
  автоматическая подача почти везде нарушает правила сайтов и портит репутацию
  работодателя. Программа готовит документы, отправляете вы сами.

## 2. Лицензия QuestPDF (Community)

Проект использует [QuestPDF](https://www.questpdf.com/) в редакции Community.

* Бесплатно для физических лиц и организаций с **годовым валовым оборотом
  менее 1 000 000 USD**.
* **Не имеют права использовать Community-лицензию независимо от оборота:**
  государственные органы, государственные организации и публичные акционерные
  общества. Если вы работаете в государственной организации Республики Беларусь —
  вам нужна профессиональная лицензия QuestPDF, а этот бинарник вам не подходит.
* При превышении порога оборота — переходный период 90 дней на покупку платной
  лицензии либо прекращение использования.
* При распространении запрещено удалять или скрывать встроенные уведомления
  QuestPDF. Дословная формулировка проходит в PDF как атрибуция
  «Built with QuestPDF».
* Дословные условия: <https://www.questpdf.com/license/community.html>

Приложение проверяет тип лицензии в рантайме и **падает с внятной ошибкой**,
если лицензия изменилась (см. `патч 01 — RFC-001, Приложение A`).

## 3. AI-провайдеры и ваши данные

* Ключи API хранятся **только** на вашей машине и только в запрещённых
  репозиторию файлах (`.gitignore`). Программа не отправляет ключи никуда, кроме
  выбранного вами AI-провайдера.
* Текст вакансии, ваше резюме и текст отклика уходят выбранному AI-провайдеру.
  Если это критично — используйте локальный профиль (`me`) с локальной моделью.
* Условия и лимиты сторонних AI-провайдеров меняются без предупреждения.
  Актуальные лимиты OrcaRouter публикуются по
  `GET https://api.orcarouter.ai/api/free-package/public` — программа читает их
  в рантайме, а не хранит вшитыми числами.

## 4. Подпись и SmartScreen

Программа распространяется как zip без подписи кода. Windows SmartScreen
покажет предупреждение — это **нормально для новой программы**, а не признак
вируса. Инструкция по безопасному запуску: `troubleshooting.md`, раздел
«SmartScreen / Windows защитила ваш компьютер».

## 5. Гарантии

Программа предоставляется «как есть», без гарантий, в том числе без гарантии
пригодности для конкретной цели. Ответственность автора ограничена размером
фактически полученного ущерба.
