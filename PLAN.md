## 2. Правила игры (проверяются CI, не обсуждаются)

- Реестр config/registry.json — единый источник правды по порталам.
- Числа в README — только генератором: `python tools/gen_readme_counters.py`;
  CI-гейт `git diff --exit-code -- README.md` роняет сборку при ручных
  правках счётчиков.
- Файлы репо: UTF-8 без BOM, переводы строк LF, документация на русском.
- Ключи — только в `%APPDATA%\ai-job-search-by\local.json` (вне репо;
  legacy-путь config/local.json остаётся в .gitignore как defense-in-depth);
  личные данные — только `%APPDATA%\ai-job-search-by\` (data/ в .gitignore);
  секреты и личные конфиги в гит не попадают (secrets-guard).
- Python в runtime продукта запрещён (DECISIONS.md, RFC-001): только
  one-shot-утилиты в tools/ с PYDOC-шапкой. Продукт — C# / .NET 10 (Avalonia).
- Приватные проекты и файлы владельца в репозиторий не попадают и в доках
  не упоминаются (категоричное правило владельца).
- Вежливый обход источников обязателен: robots.txt, паузы, никаких
  параллельных LLM-запросов.

## 4. Решения, которые нельзя ломать (выжимка architecture.md §10)

- Слои конфига: код-дефолты ← app.json ← local.json (gitignore); битый json =
  quarantine + дефолты, не крах.
- Снапшот порядка порталов и конфига фиксируется на старте прогона.
- Дедуп по композитному ключу ДО нормализации текста.
- Поиск ≠ подача: ApplySupported/ApplyWarning; подача только с подтверждением
  пользователя.
- LlmClient — одна попытка без ретраев; ретраи — собственность оркестратора;
  Retry-After сервера главнее.
- EndpointGate сериализует LLM-запросы; отказ провайдера ≠ крах прогона.
- Без Entity Framework; экспорт без LaTeX/Typst в v1; без TabControl; без
  параллельных LLM-запросов; ключи и личные данные вне git.
- Документация синхронна коду: коммит фазы = код + доки вместе.

## 5. Как работать с планом

- Выполненное помечается `[x]` и переносится в «Готово» (§12) с датой.
- Один WP = одна фаза = один коммит `phase-N` с обновлёнными доками в том же
  коммите (architecture.md §1): код без синхронной документации не коммитится.
- Перед кодом каждого портала — карточка в реестре + ToS-evidence
  (гейт-чеклист из architecture.md §3.3; полная версия — DECISIONS.md,
  RFC-003 §2.11): портал без карточки не кодится.
- В конце каждой сессии обновляется этот файл — порядок в §11.
