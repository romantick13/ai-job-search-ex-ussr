# Конфиденциальность: что происходит с вашими данными

Программа локальная: без аккаунтов, без телеметрии, без облака, без
синхронизации. У неё нет собственного сервера, и данные основной базы
не покидают ваш компьютер. Но «локальная» не значит «в сеть не ходит
ничего и никогда»: при отдельных, явно запущенных вами действиях часть
данных уходит наружу — к сайтам вакансий и к ИИ-провайдерам. Этот документ
говорит точно: что уходит, кому и когда. Юридическая сторона использования
сторонних сайтов — в [DISCLAIMER.md](DISCLAIMER.md); хранение ключей и
сообщение об уязвимостях — в [SECURITY.md](SECURITY.md).

## Коротко: таблица потоков

| Ваше действие | Что уходит наружу | Кому |
|---|---|---|
| Установка, запуск программы | ничего | — |
| Стартовая проба провайдеров (лампы цепи) | HTTP-запрос каталога моделей `GET …/models`; с ним — ваш ключ этого провайдера (если задан) | только тому провайдеру |
| Поиск вакансий (кнопка «Искать») | поисковый запрос: ваши слова + регион, с браузерными заголовками | hh-группе (rabota.by) и/или включённым remote-фидам |
| Смежные запросы от ИИ | короткий текст вашего запроса («SAP администратор») | ИИ-провайдеру из цепи |
| «Адаптировать» | системный промпт программы, текст вашего резюме, текст выбранной вакансии | ИИ-провайдеру из цепи (облачному или локальному — см. ниже) |
| Сопроводительное письмо | то же самое | ИИ-провайдеру из цепи |
| Ввод ключа в настройках | ключ | только тому сервису, которому ключ принадлежит |
| Всё остальное (база, фильтры, CSV, PDF, история) | ничего | — |

Фоновых отправок не существует: без ваших действий программа только *читает*
публичные ленты вакансий и ничего не посылает — ни резюме, ни запросов к ИИ.
Телёметрии нет — и не будет.

## Что уходит в облако ИИ-провайдеров

**Что именно.** Промпт, который программа собирает для конкретного действия:
системная инструкция программы, текст выбранной вакансии и текст вашего
резюме из активного профиля. Отправка происходит только по явному действию —
нажатию кнопки. Программа не отправляет резюме «про запас» и не запускает
адаптацию сама при появлении новых вакансий.

**Кому.** Цепочка провайдеров — запрос получает тот, до кого дошла очередь.
Состав и порядок цепи: [docs/PROVIDERS.md](docs/PROVIDERS.md). Важно понимать
два полюса:

* **локальная ступень (LM Studio / Ollama, localhost)** — промпт не покидает
  вашу машину в принципе;
* **облачные ступени (llm7 анонимно, ModelScope, SiliconFlow, OpenRouter,
  OrcaRouter)** — запрос уходит в интернет. Анонимный llm7 работает без
  аккаунта; у остальных запрос привязан к вашему ключу.

Если нужен режим без облачных запросов вообще — снимите галочки с облачных
звеньев цепи в интерфейсе (как проверить, что облачных запросов нет, —
в [docs/PROVIDERS.md](docs/PROVIDERS.md#полностью-локальный-режим)).

**Векторизации больше нет.** Подсистема векторов откликов вырезана в r21
(решение владельца: векторы ничего не потребляли) — этой категории передачи
данных в сборке не существует; прежняя лестница «LM Studio → SiliconFlow →
OpenRouter» удалена целиком.

**Как запрос обрабатывается на той стороне, программа не контролирует:**
провайдер применяет свою политику конфиденциальности (сайт провайдера →
Privacy Policy). Программа не может гарантировать удаление промпта у
провайдера. Практическое правило: в профиль резюме кладите те данные о себе,
которые готовы показать обработчику запроса, — как при отправке отклика
живому человеку.

**Что не уходит никогда:** ключи API не попадают в промпты и журналы
(проверяется тест-гардом); содержимое локальной базы, файлы документов,
настройки и логи никуда не отправляются. Ключ сервису отправляется только
по назначению: ключ провайдера — этому провайдеру, ключ портала — этому
порталу.

## Что уходит сайтам вакансий

**hh-группа (rabota.by):** HTTP-запрос страниц выдачи с вашими поисковыми
словами и регионом, с заголовками обычного браузера. Программа не входит в
аккаунт, не отправляет резюме и не подаёт отклики автоматически — сайту
нечего о вас знать сверх самих поисковых слов и IP-адреса, который видит
любой сайт.

**Шесть remote-фидов** (RemoteOK, Remotive, Himalayas, Jobicy,
WeWorkRemotely, NoDesk): те же публичные запросы за лентой/поиском, без
авторизации.

**Автоматической подачи откликов нет** — намеренно: программа никогда ничего
не отправляет сайтам от вашего имени. Документы собираются локально, а
отклик вы делаете сами на сайте.

## Что остаётся локально

Всё, что создаёт программа, живёт в профиле пользователя
(`C:\Users\<юзер>\ai-job-search-by\`) и в папке программы:

| Файл/папка | Что это | Секреты |
|---|---|---|
| `state\local.json` | ключи API | не прикладывать к баг-репортам никогда |
| `state\keywords.json`, `state\llm7-budget.json` и др. | словарь ключевых слов, счётчики квот | нет |
| `state\session-checks.log` | журнал проб провайдеров | нет |
| `data\ai-job-search-by.db` | база вакансий, откликов, настроек | личные данные |
| `resume\` | профили резюме и распознанные тексты | личные данные |
| `logs\ai-job-search-by-ГГГГММДД.log` | протокол по дням | ключей нет (гард-тест); тексты вакансий — есть |
| `<папка программы>\resume\`, `exports\` | PDF откликов, CSV-выгрузки | личные данные |

В репозитории и в релизном zip ключей и личных данных нет по построению:
конфиги с ключами закрыты `.gitignore`, тест-гард сканирует код на
ключеобразные строки.

## Как удалить всё полностью

1. Удалите папку программы.
2. Удалите `C:\Users\<юзер>\ai-job-search-by\` — база, ключи, профили,
   журналы живут только там.

Удаление локальной копии не удаляет историю у облачных провайдеров с
аккаунтом: запросы и их обработка — предмет политики того сервиса, удалять
нужно в его кабинете. У анонимного llm7 аккаунта нет.
