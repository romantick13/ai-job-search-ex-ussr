# Установка и обновление

Актуально для Windows 10 1809+ / Windows 11, x64. .NET устанавливать не нужно —
внутри релизного zip self-contained рантайм. Скачивайте программу **только из
официального раздела Releases репозитория** — из других мест дистрибутив
приходит без гарантий целостности.

## Установка с нуля

1. Скачайте `ai-job-search-by-…-win-x64.zip` из Releases.
2. (Рекомендуется) Сверьте контрольную сумму — см. [ниже](#проверка-контрольной-суммы-sha256).
3. Распакуйте в папку **без прав администратора**, например `C:\Tools\ai-job-search-by`.
4. Запустите `ai-job-search-by.exe`. При первом запуске Windows может показать
   SmartScreen — см. [соответствующий раздел](#smartscreen--windows-защитила-ваш-компьютер).

Не запускайте из `C:\Program Files`: программе нужно писать рядом с собой
(папки откликов `resume\` и выгрузок `exports\`), а держать исполняемые файлы
в месте, защищённом от записи, — плохая идея в обе стороны.

## Проверка контрольной суммы (SHA256)

Проверка подтверждает, что файл по дороге не изменился и совпадает с тем,
что опубликовано в релизе. Она **не** заменяет официальный источник: сумма
полезна, только если её выложил сам автор релиза (в заметках релиза или
файле `.sha256` рядом с архивом).

В Windows: откройте папку с zip в Проводнике, затем в адресной строке
напишите `cmd` и Enter — откроется консоль в этой папке:

```bat
certutil -hashfile ai-job-search-by-…-win-x64.zip SHA256
```

Сравните первую строку вывода с суммой из заметок релиза. Совпадает — файл
целый. Не совпадает — скачайте заново; если разница повторяется, заведите
issue (шаблон bug_report) и не запускайте файл.

## SmartScreen / «Windows защитила ваш компьютер»

При запуске неподписанного exe Windows показывает окно «Windows защитила ваш
компьютер». Что это значит на самом деле: у файла без цифровой подписи и
истории загрузок **ещё нет репутации**, поэтому SmartScreen не может сказать
ни «безопасно», ни «опасно». Предупреждение — не признак вируса, но и его
отсутствие/обход — не признак безопасности. Поэтому разумный порядок такой:

1. Убедитесь, что архив скачан из официального Releases и его SHA256
   совпадает с опубликованным (см. раздел выше).
2. Нажмите **«Подробнее»** → **«Выполнить в любом случае»**.
3. При следующих запусках предупреждение повторится только для нового файла.

Чего делать не надо:

* ❌ Не отключайте SmartScreen целиком в «Безопасность Windows» — защита
  нужна всей системе, а предупреждение снимается одной кнопкой.
* ❌ Не ищите exe «на другом сайте, где нет предупреждения» — так вы
  скачиваете не то, что выложил автор.
* ❌ Не запускайте от имени администратора — программе это не нужно.

**Если предупреждение появляется у каждого распакованного файла:** zip,
скачанный из интернета, несёт пометку «внешнего файла» (Mark of the Web), и
все извлечённые из него файлы её наследуют. Снимите пометку **с zip до
распаковки**: правый клик по zip → Свойства → кнопка «Разблокировать» → ОК →
распаковывайте. У файлов из разблокированного архива пометки не будет.

**Корпоративные машины:** политики безопасности блокируют неподписанные
исполняемые файлы жёстко, без «Выполнить в любом случае». На такой машине
программа не запустится — это ограничение политики, не бага.

Мы не используем цифровую подпись: OV-сертификат стоит $150–300 в год, и
даже он не убирает SmartScreen для нового файла (предупреждение уходит только
по мере накопления репутации загрузчика).

## Как обновиться

**Одно правило для всех релизов:**

1. Закройте работающую программу.
2. **Сохраните черновики откликов из старой папки программы** — папки
   `resume\` (адаптированные PDF) и `exports\` (CSV-выгрузки). Они лежат
   рядом с exe и на шаге 3 удалятся вместе со старой папкой: скопируйте их
   в сторону (например, на рабочий стол) и верните в новую папку после
   распаковки.
3. Удалите старую папку программы целиком.
4. Распакуйте новый zip в чистую папку.

База вакансий, ключи, профили резюме и журналы лежат в
`C:\Users\<юзер>\ai-job-search-by\`, а не рядом с exe — новая сборка
подхватит их автоматически, эти данные шаг 3 не трогает. Не смешивайте
файлы старой и новой сборки в одной папке: программа собирается из многих
файлов, половинная замена даёт труднообъяснимые сбои.

Перед обновлением на версию, помеченную в заметках релиза как «несовместимая
с прошлой базой», сделайте копию `C:\Users\<юзер>\ai-job-search-by\`.

## Как удалить

1. Удалите папку программы (в ней — PDF откликов `resume\` и выгрузки
   `exports\`; если нужны — скопируйте заранее).
2. Удалите `C:\Users\<юзер>\ai-job-search-by\` — база, ключи, профили и
   журналы живут только там. После этих двух шагов машина чистая
   (облачные провайдеры с аккаунтом хранят историю запросов у себя — см.
   [PRIVACY.md](../PRIVACY.md)).

## Если программа не запускается вообще

* Проверьте, что zip распакован полностью (не запускайте exe прямо из архива).
* Проверьте, что распаковали в обычную папку, а не в `Program Files`.
* Проверьте, что система 64-разрядная: Проводник → Этот компьютер →
  Свойства → Тип системы.

Остальные проблемы — в [docs/TROUBLESHOOTING.md](TROUBLESHOOTING.md).
